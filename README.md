## Descripción del Proyecto
[cite_start]Este proyecto consite en una web informatica para una **Jornada Tecnologica** local[cite: 2, 10]. [cite_start] El ovjetivo es presentar el evento de forma atractiva, detallando qué es, cuándo y dónde se celebran[cite: 4, 5].

## Estructura y Diseñó (Bootstrap 5)
[cite_start] La web ha sudo diseñada sigueindo una estctura resposive para poderse adaptarse a móviles, tablets e ordenadores[cite: 6, 21]:
* [cite_start]**Navbar**: Barra de navegación superior para acceso mucho mas rápido[cite: 26].
* [cite_start]**Hero**: Sección de impacto con el título principal del evento[cite: 27].
* [cite_start]**Sección de Información (Grid)**: Uso de sistema de 3 columnas (`col-md-4`) para los datos principales[cite: 28, 75]. * * 
* [cite_start]**Sección de Detalles (Grid)**: Uso de sistema de 2 columnas (`col-md-6`) para infromatción extendida [cite: 28].
* [cite_start]**Componentes**: Se han implementado **Cards** de Bootstrap para organizar los talleres y potencias [cte: 29].
* [cite_start]**Footer**: Pie de página con información de contacto y créditos [cite: 30].
